# Projeto 03 — Análise de Dados com IA Aplicada (Python + LLMs)

**Status:** 🟡 Planejado (Fase 3 — Abr/2027)

## 🎯 Problema de Negócio
Criar uma aplicação analítica interativa que combine análise de dados tradicional com Inteligência Artificial Generativa para gerar resumos executivos, responder perguntas em linguagem natural e sinalizar anomalias em bases de dados.

## 🛠️ Stack Prevista
- **Aplicação:** Python + Streamlit.
- **Dados e IA:** Pandas + API de LLM / Agente de IA.
- **Ambiente:** Git/GitHub + noções de Docker/Cloud.

## 📦 Entregáveis
- [ ] Interface funcional para upload/consulta de dados
- [ ] Integração com agente de IA para geração de insights
- [ ] Documentação de arquitetura e demonstração de uso
