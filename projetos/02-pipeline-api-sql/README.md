# Projeto 02 — Pipeline Analítico com API e Banco de Dados (Python + SQL)

**Status:** 🟡 Planejado (Fase 3 — Abr/2027)

## 🎯 Problema de Negócio
Automatizar a coleta, limpeza e armazenamento estruturado de dados reais obtidos via API pública para viabilizar consultas analíticas recorrentes sem trabalho manual.

## 🛠️ Stack Prevista
- **Extração e Testes:** Python (`requests`) e Postman.
- **Tratamento:** Python (`Pandas`).
- **Armazenamento e Análise:** Banco de dados relacional + SQL.

## 📦 Entregáveis
- [ ] Script de consumo da API e tratamento dos dados
- [ ] Carga estruturada em banco de dados
- [ ] Consultas SQL respondendo perguntas de negócio
