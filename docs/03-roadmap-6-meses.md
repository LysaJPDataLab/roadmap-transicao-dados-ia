# 03 — Roadmap de Estudos e Transição (Dez/2026 a Mai/2027)

Roadmap estruturado sobre os pilares de escolha de área, fundamentos, prática frequente, criação de projetos, ferramentas de mercado e preparação para vagas, adaptado integralmente para **Análise de Dados e IA**.

## Filtro de Escopo (Adaptação para Dados)
- **Prioridade Máxima:** Python para Dados, lógica de programação, estruturas de dados básicas, SQL, Git/GitHub, APIs/Postman, Docker, noções de Cloud (AWS/GCP), Power BI e IA aplicada.
- **Fora do escopo agora (adiado/cortado):** Java, C++, POO aprofundada, redes/sistemas operacionais densos, operações CRUD de back-end e programação competitiva (Codeforces).

## Fase 1 — Fundamentos e Versionamento (Dez/2026 – Jan/2027)
**Objetivo:** Dominar a base de consulta e manipulação de dados e perder o medo do terminal/Git.

- **SQL (Hotmart — SQL com IA aplicada):** `SELECT`, `WHERE`, `GROUP BY`, `HAVING`, `ORDER BY`, `JOINs` (INNER, LEFT), Subqueries, CTEs e *Window Functions*.
- **Python (Asimov Academy):** Lógica de programação, tipos de dados, listas, dicionários, loops, funções e introdução a manipulação de arquivos/tabelas.
- **Git & GitHub (Alura):** Fluxo diário no VS Code (`init`, `status`, `add`, `commit`, `push`, `pull`, `branch`).
- **Entregáveis da Fase 1:**
  - [ ] Repositório de estudos ativo com commits semanais.
  - [ ] 20+ queries SQL resolvidas e versionadas.
  - [ ] 1ª automação simples de limpeza de planilha testada na rotina de trabalho.

---

## Fase 2 — Prática Diária, Pandas e BI com Visual de Produto (Fev/2027 – Mar/2027)
**Objetivo:** Transformar conhecimento técnico em análise exploratória e dashboards executivos.

- **Prática frequente (30–60 min):** Resolução de desafios de SQL e Pandas no **HackerRank** e **LeetCode** (trilha de Database), revisão de conceitos e aplicação em casos reais.
- **Python para Dados (Asimov):** Pandas (limpeza, filtros, agrupamentos, merge), NumPy e visualização exploratória.
- **Power BI (Alura):** Modelagem *Star Schema*, Power Query avançado, medidas DAX intermediárias e storytelling com dados.
- **UI para Dashboards (EBAC — consulta pontual):** Aulas específicas de Figma, grid, tipografia e contraste para criar layouts profissionais para o Power BI.
- **Inglês (Marco de evolução):** Iniciar leitura de documentações curtas em inglês e introduzir vocabulário de trabalho/dados nas aulas do Cambly.
- **Entregável da Fase 2:**
  - [ ] **Projeto 1 concluído e publicado:** *A Ponte de O&M para Dados* (SQL + Power BI + Figma) — painel de indicadores operacionais/confiabilidade (disponibilidade, MTBF/MTTR, SLA) com dados 100% sintéticos.

**Objetivo:** Construir projetos de ponta a ponta aprendendo ferramentas de mercado na prática, não na teoria isolada.

- **Ferramentas no contexto dos projetos (Alura + documentação):** Consumo de APIs e testes no Postman, comandos básicos de Linux, noções de Docker e visão prática de Cloud (AWS ou Google Cloud).
- **Entregáveis da Fase 3 (Regra: 3 projetos completos > 20 inacabados):**
  - [ ] **Projeto 2 concluído e publicado:** *Pipeline Analítico com API e Banco de Dados* — extração de dados reais via API pública (testada no Postman), tratamento em Python/Pandas, carga em banco de dados e análise em SQL.
  - [ ] **Projeto 3 concluído e publicado:** *Análise de Dados com IA Aplicada* — aplicação interativa (ex.: Streamlit + Python + LLM/Agente de IA) que analisa uma base de dados e gera resumos executivos ou detecção de anomalias.
