**Objetivo:** Dominar a base de consulta e manipulação de dados e perder o medo do terminal/Git[cite: 2, 5].

- **SQL (Hotmart — SQL com IA aplicada):** `SELECT`, `WHERE`, `GROUP BY`, `HAVING`, `ORDER BY`, `JOINs` (INNER, LEFT), Subqueries, CTEs e *Window Functions*[cite: 2].
- **Python (Asimov Academy):** Lógica de programação, tipos de dados, listas, dicionários, loops, funções e introdução a manipulação de arquivos/tabelas[cite: 2].
- **Git & GitHub (Alura):** Fluxo diário no VS Code (`init`, `status`, `add`, `commit`, `push`, `pull`, `branch`)[cite: 5].
- **Entregáveis da Fase 1:**
  - [ ] Repositório de estudos ativo com commits semanais.
  - [ ] 20+ queries SQL resolvidas e versionadas.

## Fase 2 — Prática Diária, Pandas e BI com Visual de Produto (Fev/2027 – Mar/2027)
**Objetivo:** Transformar conhecimento técnico em análise exploratória e dashboards executivos.

- **Prática frequente (30–60 min):** Resolução de desafios de SQL e Pandas no **HackerRank** e **LeetCode** (trilha de Database), revisão de conceitos e aplicação em casos reais[cite: 3].
- **Python para Dados (Asimov):** Pandas (limpeza, filtros, agrupamentos, merge), NumPy e visualização exploratória.
- **Power BI (Alura):** Modelagem *Star Schema*, Power Query avançado, medidas DAX intermediárias e storytelling com dados.
- **UI para Dashboards (EBAC — consulta pontual):** Aulas específicas de Figma, grid, tipografia e contraste para criar layouts profissionais para o Power BI.
- **Inglês (Marco de evolução):** Iniciar leitura de documentações curtas em inglês e introduzir vocabulário de trabalho/dados nas aulas do Cambly.
- **Entregável da Fase 2:**
  - [ ] **Projeto 1 concluído e publicado:** *A Ponte de O&M para Dados* (SQL + Power BI + Figma) — painel de indicadores operacionais/confiabilidade (disponibilidade, MTBF/MTTR, SLA) com dados 100% sintéticos[cite: 4].
