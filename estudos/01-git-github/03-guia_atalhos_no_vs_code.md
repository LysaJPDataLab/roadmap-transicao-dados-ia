# ⌨️ Guia Prático de Atalhos de Teclado no VS Code

Este guia reúne os principais atalhos de teclado para otimizar o fluxo de trabalho durante a navegação, edição e uso do Git no Visual Studio Code.

---

## 1. 🖥️ Terminal Integrado
* `Ctrl + '` (ou `Ctrl + ~`): Abre ou oculta o terminal integrado.
* `Ctrl + Shift + '`: Abre um novo terminal simultâneo.
* `Ctrl + C`: Interrompe a execução de um processo travado ou em loop no terminal.

---

## 2. 🗂️ Navegação de Arquivos e Abas
* `Ctrl + P`: Busca rápida de arquivos por nome para abrir sem usar o mouse.
* `Ctrl + Tab`: Alterna rapidamente entre as abas abertas no editor.
* `Ctrl + W`: Fecha a aba atual.
* `Ctrl + Shift + T`: Reabre a última aba fechada por engano.
* `Ctrl + \`: Divide a tela do editor em dois painéis lado a lado.
* `Ctrl + B`: Mostra ou oculta o painel lateral (*Explorer*).

---

## 3. 📝 Edição e Manipulação de Texto
* `Ctrl + S`: Salva o arquivo atual.
* `F2` (no Explorer): Renomeia o arquivo ou pasta selecionada.
* `Alt + Seta para Cima / Baixo`: Move a linha de código atual para cima ou para baixo.
* `Shift + Alt + Seta para Cima / Baixo`: Duplica a linha atual para cima ou para baixo.
* `Ctrl + D`: Seleciona a próxima ocorrência da palavra destacada para edição simultânea.
* `Ctrl + Z` / `Ctrl + Y`: Desfaz / Refaz a última ação.

---

## 4. 📄 Documentação e Markdown
* `Ctrl + Shift + V`: Abre a pré-visualização (*Preview*) completa do arquivo Markdown.
* `Ctrl + K` depois `V`: Abre a pré-visualização em janela dupla (lado a lado com o código).

---

## 5. 🐙 Controle de Versão (Git)
* `Ctrl + Shift + G`: Abre a aba de Controle de Fonte (*Source Control*) para visualizar arquivos modificados.
